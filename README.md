# Multilingual Spam Detection Dataset (KZ/RU/EN)

## Описание
Датасет для бинарной классификации спам-сообщений. Главная особенность набора данных — наличие локального казахстанского контекста (мошеннические рассылки и фишинг от имени Kaspi, eGov, Kcell, OLX и т.д.). Так как готовых KZ-датасетов в открытом доступе практически нет, эта база помогает обучать фильтры, адаптированные под наш регион.

## Статистика набора данных
- **Общее количество записей:** 126,060 сообщений
- **Баланс классов:** ~115,000 (не спам) / ~10,900 (спам)
- **Языки:** Казахский, Русский, Английский

## Сбор данных
Данные собирались из трех основных источников:
1. **Открытые датасеты (Kaggle/UCI):** База для распознавания стандартного англо- и русскоязычного спама.
2. **Генерация через ИИ:** Создание синтетических данных, имитирующих специфичный казахстанский фишинг и спам-рассылки.
3. **Ручной парсинг:** Сбор реальных спам-сообщений из открытых источников (социальные сети, форумы).

## Формат данных (Разметка)
Данные представлены в формате CSV и имеют бинарную разметку:
- `label = 0` — Нормальное сообщение (Ham)
- `label = 1` — Спам (Spam)
